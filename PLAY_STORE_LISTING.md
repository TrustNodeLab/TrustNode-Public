## Full Description
TrustNode is an intelligent on-device fraud protection system that detects phishing, social engineering, and financial scams in real time — without sending your personal data to external servers.

**How It Works**
TrustNode uses a multi-layered AI engine to analyze messages, calls, and screen content for fraud indicators. All processing happens locally on your device.

**Key Features**
• Real-time screen monitoring — detects scams in messengers and browsers
• Call fraud detection — identifies social engineering during phone calls
• Voice analysis — detects voice-based fraud patterns during calls (on-device speech-to-text)
• URL & link scanning — local heuristics and blocklists, no external services
• BERT AI model — on-device neural network for text fraud detection
• 4 on-device education cards for fraud awareness (phishing, online safety, scam calls, banking)
• Accessibility-focused interface with elderly mode
• No account required — all data stays on your device

**Permissions Required**
• Accessibility Service — to scan screen content for real-time fraud detection
• Overlay — to show fraud warnings over other apps
• Phone — to monitor incoming calls for scam detection
• Microphone — to analyze voice during calls (only with explicit user consent, off by default)
• Notifications — to alert you about detected threats

**Privacy First**
• 100% on-device processing by default
• No personal data sent to external servers without explicit consent
• Transparency Engine logs all data access
• PII redaction before AI processing
• Encrypted storage for all sensitive data
